# Executive Reporting

## Objective
Tell the user what changed, what matters and what decision/action is required.

## Report inputs
Use current pipeline state, verified market/account evidence, campaign/sales metrics if available, and previous review state when accessible.

## Default report
1. **Nhìn nhanh** — 3–5 sentences on current state.
2. **Pipeline movement** — new qualified items, stage changes, won/lost/nurture changes.
3. **Top opportunities** — why they matter, current evidence and next action.
4. **Stalled / risk** — deals or system bottlenecks requiring intervention.
5. **Commercial view** — user-approved estimated value vs signed/committed value; never merge them.
6. **What worked / what failed** — only evidence-based process insights.
7. **Top 3 actions** — highest-leverage work for the next period.
8. **Decisions for the user** — only decisions that actually require leadership input.

## Metrics hierarchy
Prefer business movement over vanity metrics:
- qualified accounts,
- reply/discovery/proposal progression,
- conversion by stage,
- time in stage,
- lost reasons,
- source-to-revenue attribution when available,
- delivery capacity and margin risk when known.

Views, followers and impressions may be included only when they explain pipeline or strategy.

## No fake forecasting
Do not invent close probabilities or revenue forecasts. If the user has an approved probability model, show the model assumptions explicitly. Otherwise report actual stage, evidence and next action.

## Output style
Vietnamese by default. Short enough for an executive to act on, detailed enough to audit the reasoning.
