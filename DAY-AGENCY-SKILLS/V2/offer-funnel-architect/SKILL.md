# Offer & Funnel Architect

## Workflow
1. Define the target segment and trigger problem.
2. Translate features into business outcomes and proof.
3. Identify main objections: price, trust, timing, complexity, internal capability, risk.
4. Build the offer stack: core outcome, scope, proof, risk reduction, timeline, CTA and next step.
5. Choose funnel type based on buying friction: direct lead, audit/consultation, content-to-lead, webinar/event, ecommerce, remarketing or account-based outreach.
6. Map each stage: awareness → consideration → intent → lead → qualification → proposal → sale → retention.
7. Match message to stage. Avoid one generic message across the full funnel.
8. Design conversion assets: landing page, lead form, case proof, FAQ, proposal path, follow-up sequence.
9. Define handoff rules between marketing and sales.
10. Create validation tests before scaling spend.

## Offer test questions
- Is the problem urgent enough?
- Is the outcome concrete?
- Is the proof believable?
- Is the next step low-friction?
- Is the promise compatible with delivery capacity?
- Does the economics work after acquisition and delivery costs?

## Output
`ICP → Trigger → Problem → Promise → Proof → Offer stack → Funnel map → Messaging by stage → Conversion assets → Sales handoff → Test plan → KPIs`.

## Guardrails
No guaranteed outcomes. Do not invent testimonials or case results. Use clear assumptions when pricing or economics are incomplete.
