# DAY AGENCY SKILLS — V2: Growth OS

V2 upgrades the V1 skill library from isolated playbooks into an orchestrated growth operating system.

## Core idea
Do not jump from a request straight to content or ads. Diagnose the business constraint first, select the right skill chain, produce an execution plan, define measurement, then iterate from evidence.

## V2 stack
1. `day-growth-os` — master router and orchestrator.
2. `growth-diagnostic` — diagnose the growth constraint before prescribing tactics.
3. `offer-funnel-architect` — build offer, message, funnel and conversion path.
4. `paid-growth-engine` — paid media planning, testing and optimization.
5. `sales-crm-engine` — lead handling, qualification, follow-up and closing system.
6. `analytics-experimentation` — KPI tree, experiment backlog and learning loop.

## V1 skills reused
V2 can call the existing skills: `brand-context`, `social-media-strategy`, `competitor-intelligence`, `content-engine`, `lead-generation`, `short-video-strategy`.

## Default operating sequence
`Context → Diagnosis → Evidence → Strategy → Offer/Funnel → Execution → Measurement → Learn → Iterate`

## Non-negotiables
- Separate DAY AGENCY internal learning from client-specific facts.
- Use fresh public research when market or platform information may have changed.
- Never invent metrics, leads, competitors, contact details or case-study results.
- Prefer business outcomes over vanity metrics.
- Every recommendation must state: reason, expected impact, effort, owner/next action and measurement.
- Keep outputs practical for a Vietnam-based communications/media agency serving businesses that need digital growth.
