# Sales & CRM Engine

## Workflow
1. Define lead sources and expected buying journey.
2. Create qualification criteria: fit, need, urgency, authority, budget range, delivery feasibility and next-step commitment.
3. Map pipeline stages with clear entry/exit criteria.
4. Build response-speed rules and ownership.
5. Create discovery questions around current state, desired outcome, cost of inaction, decision process and constraints.
6. Build objection library: price, timing, trust, comparison, internal team, approval, scope.
7. Create follow-up sequence using new value/proof each touch; avoid repetitive 'checking in'.
8. Design proposal logic: diagnosis → objectives → scope → milestones → responsibilities → measurement → commercial terms → next step.
9. Review lost deals for recurring causes and feed learning back to offer/marketing.

## Pipeline baseline
New → Researched → Qualified → Contacted → Replied → Discovery → Proposal → Negotiation → Won/Lost → Expansion.

## Metrics
Speed-to-lead, contact rate, qualified rate, meeting rate, proposal rate, proposal-to-close, sales cycle, average contract value, loss reasons and source-to-revenue.

## Output
`ICP/qualification → Pipeline → SLA → Discovery guide → Objection handling → Follow-up cadence → Proposal structure → CRM fields → Dashboard → Improvement loop`.

## Guardrails
Do not use deceptive urgency or fabricated scarcity. Do not invent prospect information.
