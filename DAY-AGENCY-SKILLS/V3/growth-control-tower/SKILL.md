# Growth Control Tower

## Purpose
Coordinate the full growth system rather than optimizing one channel in isolation.

## Inputs
Business goal, time horizon, current baseline, constraints, team capacity, budget, active offers, existing channels and known risks.

## Control loop
1. Establish the north-star business outcome and time horizon.
2. Load DAY brand context or create temporary client context.
3. Run `growth-diagnostic` to identify the primary constraint.
4. Gather evidence with relevant specialist skills.
5. Build 2–3 strategic options with trade-offs instead of one premature answer.
6. Run `strategy-red-team` on the leading option.
7. Select a skill chain and execution sequence.
8. Translate into a 30/60/90-day operating plan.
9. Define resource needs, dependencies, owners and decision gates.
10. Use `analytics-experimentation` and `executive-growth-review` to close the loop.

## Portfolio lens
Review work across six systems:
- Demand creation
- Demand capture
- Conversion
- Sales
- Retention/expansion
- Operating capability

Do not allow a single channel to dominate strategy simply because it is easiest to measure.

## Decision board
For each major initiative record:
`Problem → Evidence → Hypothesis → Option → Expected upside → Downside/risk → Resource cost → Dependency → KPI → Decision date → Status`.

## Scenario planning
For material decisions, create:
- Base case: expected execution conditions.
- Upside case: what becomes possible if signals are strong.
- Downside case: what to cut/protect if results are weak.

Do not fabricate numeric forecasts. Use ranges only when grounded in real data and label assumptions.

## Output
`Executive diagnosis → Strategic options → Chosen sequence → Skill chain → 30/60/90 plan → Resource map → KPI tree → Risks → Decision gates → Next 3 actions`.
