# Executive Growth Review

## Inputs
Current goals, KPI dashboard, campaign results, sales pipeline, content performance, delivery capacity, experiment log and notable market changes.

## Review sequence
1. Reconfirm the business objective and current primary constraint.
2. Compare actual vs planned outcomes; explain meaningful variance.
3. Review funnel from attention → traffic → lead → qualified lead → proposal → revenue.
4. Review sales response speed, follow-up and loss reasons.
5. Review content/creative: which messages and formats created qualified actions, not just reach.
6. Review economics and delivery capacity where data exists.
7. Review experiments: wins, losses, inconclusive tests and learning.
8. Identify new risks, dependencies and external changes.
9. Make explicit decisions: KEEP / STOP / FIX / TEST / SCALE.
10. Set the next review period's top 3 priorities and owners.

## Decision rules
- SCALE only when the signal supports the business objective and delivery can absorb it.
- FIX when the underlying strategy is sound but execution has a clear bottleneck.
- TEST when evidence is insufficient and a cheaper validation is available.
- STOP when evidence repeatedly contradicts the hypothesis or opportunity cost is too high.
- KEEP when performance is stable and no higher-leverage intervention is justified.

## Output
`Scorecard → Variance analysis → Funnel diagnosis → Experiment learning → Decisions → Top 3 priorities → Owners → Risks → Next review date`.

## Learning capture
Store reusable DAY AGENCY operating insights separately from client-specific facts. A client result can inspire a hypothesis, but client data should not become a universal DAY rule without repeated evidence.
