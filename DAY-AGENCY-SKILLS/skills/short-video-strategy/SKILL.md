# Short Video Strategy

## Workflow
1. Define audience, objective and desired next action.
2. Research current category patterns and audience language when freshness matters.
3. Separate trend from durable insight; do not copy viral videos shot-for-shot.
4. Build recurring formats: expert POV, teardown, before/after, myth vs reality, case/process, behind-the-scenes, rapid audit, FAQ/objection.
5. Design first 3 seconds: visual interrupt + clear tension/question + relevance.
6. Script as Hook → Context → Value/Proof → Payoff → CTA.
7. Optimize production for repeatability: shot list, captions/graphics, B-roll and reusable templates.
8. Test one meaningful variable at a time: hook, angle, length, opening visual or CTA.
9. Evaluate retention and business actions, not views alone.

## DAY production baseline
When relevant, plan sustainable batches of 10–30 short videos/month, with subtitles/graphics, publishing cadence and strong first-three-second optimization.

## Output
`Research insights → Formats → 20–30 concepts → Hook variants → Script templates → Production plan → Test matrix → KPI/iteration`.
